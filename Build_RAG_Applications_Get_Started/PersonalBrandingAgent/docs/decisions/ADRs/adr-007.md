# ADR-007 — Evidence Ranked by the Corpus's Own Hierarchy; Positioning Separated

## Status

Accepted (see `../architecture/rag-architecture.md` §Evidence states and hierarchy).

## Context

Ranking needs an order, and inventing one (recency scores, learned weights)
would substitute the system's judgement for the corpus's declared
epistemics — while letting voice/positioning documents compete as evidence
would let a manner of speaking become a claimed achievement.

## Decision

Within each context section, items order deterministically by the evidence
hierarchy the corpus itself defines (concrete repository evidence first,
inference last). Positioning, vision, and writing style travel in separate
guidance fields with their section names attached, are never counted as
evidence, and a claim resting only on guidance is a gate finding
(`GUIDANCE_AS_EVIDENCE`), never a pass.

## Consequences

- Two runs over the same retrieval result assemble byte-comparable contexts;
  ordering disputes are settled by corpus policy, not by model preference.
- Cost: hierarchy changes require corpus edits, not configuration — which is
  where the project keeps its epistemics anyway.
