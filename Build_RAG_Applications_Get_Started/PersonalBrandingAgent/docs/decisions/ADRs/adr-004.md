# ADR-004 — Evidence Grounding: Supported Claims Over Plausible Claims

## Status

Accepted (see `../architecture/rag-architecture.md`, `../evaluation/quality-gates.md`).

## Context

A fluent post about a real person is the most dangerous output this system
produces: plausibility is cheap, support is not, and no reader can tell
them apart. Instructions to "be grounded" are not checkable.

## Decision

Support is enforced by deterministic gates, not by prompting. Every draft
sentence becomes a numbered claim checked against the cited evidence only:
exact references string-matched, the corpus's five forbidden inferences as
rules, evidence states honored, guidance never counted as evidence. The LLM
support judge is advisory — consulted after the deterministic checks pass,
reported rather than trusted, never a gate. A decline (no evidence, model
refusal) is a normal result; an unverifiable draft is rejected, not
rewritten into plausibility.

## Consequences

- The system prefers no post over an unsupported one, by construction.
- A passing result cannot carry a finding (enforced in the type).
- Cost: paraphrase-level support beyond string matching is not detected;
  the gate says what it checked, honestly, rather than implying more.
