# Phase Documents

`phase-01-foundation.md` and `phase-02-ingestion.md` predate the roadmap
rewrite and are kept as historical reference. Per `docs/README.md`, phases
03–10 were never written as a series and are superseded by `PLAN.md` Steps
0–14; per-step records live in `docs/implementation-status.md`, not here.

The single exception is `phase-10-observability-memory.md`, which exists
because the ADR index (`docs/decisions/ADRs/README.md`, ADR-005) references
it. It describes operational memory as built, and stays.
