# ADR-002 — Deterministic Workflow/State Machine Before Open-Ended Agent

## Status

Accepted (see `../architecture/agent-architecture.md`).

## Context

The target is an unattended system with irreversible side effects
(publishing under the user's name, with no LinkedIn read-back). An
open-ended agent loop cannot carry that responsibility: its failure modes
are prose, not values a workflow can branch on.

## Decision

Deterministic layers own sequencing, state, and outcomes; exactly one
bounded Agent reasons about content (topic, angle, evidence selection,
publish-worthiness) and returns a typed decision. No graph runtime
(LangGraph deferred — one branch and one decision do not justify it), no
planner/critic pair, no sub-agents. The reasoner is asked once per run;
revision happens over drafts under Step 9's stopping rule, not as further
reasoning.

## Consequences

- Every run terminates in one of three recorded outcomes; `PUBLISH` is
  unconstructible without a passing verification.
- Reasoning failure becomes `DO_NOT_PUBLISH` carrying the failure for the
  workflow to notify — never a weaker fallback post.
- Cost: genuinely novel reasoning tasks beyond "what is worth publishing
  from this evidence" have no home; they need a new ADR.
