# ADR-001 — RAG Is a Capability of the Agent, Not the Agent Itself

## Status

Accepted (see `../architecture/system-overview.md`).

## Context

Retrieval over the personal knowledge base existed before any agent did
(vector, metadata, BM25, multi-query, hybrid RRF, reranked — with
comparison and evaluation tooling). The temptation was to wrap that
retriever in agent language and call the result autonomous.

## Decision

Retrieval stays a deterministic, explicitly-chosen capability
(`RetrievalEngine` facade; the caller picks the strategy). Reasoning about
*what to publish* is a separate, bounded component above it that cannot
retrieve — it is handed assembled context and selects only from what
retrieval returned.

## Consequences

- "The Agent chose a topic the evidence does not support" is structurally
  impossible: topics and evidence labels resolve against the offered options
  or the answer is refused.
- Retrieval keeps its own evaluation (gold set, Hit@K, MRR), independent of
  any model judgement.
- Cost: a retrieval-strategy choice exists as a *recommendation* the Agent
  produces for a fresh pass, not as autonomous retrieval.
